Jakarta Brand Book — Design System Findings

2026-05-22 11:22:45 WIB • Hadi K AR

Full extraction of the Jakarta Brand Book (104 pp, image-heavy) covering the +Jakarta logo anatomy, the MENOR 6-color system with district mappings, Plus Jakarta Sans typography scale, graphic pattern primitives, and icon set — all mapped to actionable ds-jakarta token and component recommendations.

Background

The ds-jakarta design token library needs to be grounded in the official Jakarta brand identity. The Brand Book (docs/JakartaBrandBook.pdf, 104 pages, created 2020, revised 2024) is the authoritative source for logo usage, the MENOR color family, typography, graphic elements, iconography, and tone of voice. This research reads the full document to extract everything reusable in a token library or component catalogue.

Scope

  • Logo anatomy and usage rules (reusable as SVG components)
  • Color system: names, HEX values, Pantone references, district assignments, combination rules
  • Typography: typeface family, weight variants, type scale with sizes
  • Graphic element primitives (squares, triangles, J-curve) and pattern system
  • Iconography style and categories
  • Tone of voice principles
  • Derived design system token and component recommendations

Out of scope: photography guidelines, application mockups, print production specs.

Findings

1. Logo Anatomy

The +Jakarta identity has two distinct marks, both derived from a 3×3 dot-grid:

  • +J Icon — a compact symbol made of squares and triangles arranged in a 3×3 grid, forming a plus sign with a J-curve emerging from the lower-right quadrant. Used standalone at small sizes, on vehicles, and as a favicon/app-icon candidate.
  • Full wordmark — the +J Icon paired with "Jakarta" set in Plus Jakarta Sans Display, with a custom lowercase j featuring a rounded descending tail that echoes the J-curve in the icon.

Logo usage rules:

  • Exclusion zone: 1× icon height clear space on all four sides
  • Approved colour combinations: white-on-brand-colour, black-on-white, single-colour monochrome
  • Minimum size enforced (exact pt values are in the PDF; digitally, 24 px icon height is a reasonable floor)
  • No distortion, rotation, recolouring outside approved palette, or drop shadows

2. Color System — MENOR Family

MENOR is the mnemonic for the six vivid brand colours (Merah, Kuning, Orange/Jingga, Biru, Pink, Biru Pesisir — loosely). Each colour maps to a Jakarta administrative district and carries a semantic meaning:

  • Six pre-approved combinations (each = 2 brand colours + white or black):

    • Hijau Betawi + Kuning Gigi Balang + White
    • Biru Pesisir + Jingga Bis Kota + White
    • Kuning Gigi Balang + Jingga Bis Kota + Black
    • Hijau Betawi + Biru Abang + White
    • Pink None + Biru Pesisir + White

3. Typography

The brand typeface is Plus Jakarta Sans, available in two optical sizes: Display (for headlines) and Text (for body copy). The font is open-source and available on Google Fonts, making it trivially embeddable.

Role (Indonesian) Proposed token Family Size Weight / Style
Judul Utama (Primary Heading) typography.scale.heading-1 Plus Jakarta Sans Display 36 pt Medium
Judul Pendukung (Secondary Heading) typography.scale.heading-2 Plus Jakarta Sans Text 22 pt Medium
Tajuk (Label / Subheading) typography.scale.label Plus Jakarta Sans Text 12 pt Bold
Paragraf (Body) typography.scale.body Plus Jakarta Sans Text 9 pt Regular

Additional supported weights: Light, Italic. Body italic is available for emphasis.

4. Graphic Primitives & Pattern System

All brand graphics derive from three primitives built on the same dot-grid as the logo:

  • Persegi (square) — solid or outlined; the most neutral element
  • Segitiga (triangle) — dynamic, directional; signals movement
  • J-curve — the brand's unique organic element; signals warmth and collaboration

These combine into two pattern families:

  • Pola Umum (General Patterns) — three complexity tiers (Simple, Medium, Complex), all using a "fireworks burst" motif with mixed primitives. Colour-agnostic; any MENOR pair applies.
  • Pola Tematik (Thematic Patterns) — four themes, each with a designated colour pair:
    1. Konektivitas & Kolaborasi — J-curves interlocking; Hijau Betawi + Biru Abang
    2. Produktivitas & Kemajuan — triangles in dynamic arrangement; Biru Pesisir + Jingga Bis Kota
    3. Sehat & Bahagia — fireworks/squares; Pink None + Kuning Gigi Balang
    4. Rumah & Tradisi — ondel-ondel-inspired shapes; Hijau Betawi + Kuning Gigi Balang

5. Iconography

  • Style: pixel-art, sharp square corners (no rounded ends), filled silhouette
  • The + symbol is embeddable into any icon at the origin point
  • ~20 icons shown across 4 categories: Pariwisata (tourism), Transportasi (transport), Umum (general), Ruang Kolaborasi (collaboration spaces)
  • Grid-aligned, making them straightforward to vectorise at consistent optical sizes

Recommendation

Color tokens

Define 8 primitive color tokens in src/tokens/color.ts using Indonesian brand names as the slug. Add district aliases as a second tier. Example: 

// src/tokens/color.ts
export const color = {
  brand: {
    hijauBetawi:       '#19ae5d',  // Jakarta Selatan
    kuningGigiBalang:  '#feb52b',  // Jakarta Barat
    jinggaBisKota:     '#fc351c',  // Jakarta Pusat
    biruAbang:         '#1c5ddc',  // Jakarta Utara
    pinkNone:          '#eb30a2',  // Jakarta Timur
    biruPesisir:       '#00aaff',  // Kepulauan Seribu
  },
  neutral: {
    black: '#000000',
    white: '#ffffff',
  },
  district: {
    selatan:    '#19ae5d',
    barat:      '#feb52b',
    pusat:      '#fc351c',
    utara:      '#1c5ddc',
    timur:      '#eb30a2',
    kepulauan:  '#00aaff',
  },
} as const;

CSS custom properties follow the Atlassian naming convention (see companion research log): --jkt-color-brand-hijau-betawi, etc.

Typography tokens

Register Plus Jakarta Sans via @fontsource/plus-jakarta-sans (open-source, npm available). Token scale maps directly to the Brand Book hierarchy: 

// src/tokens/typography.ts
export const typography = {
  fontFamily: {
    display: '"Plus Jakarta Sans Display", sans-serif',
    text:    '"Plus Jakarta Sans", sans-serif',
  },
  fontSize: {
    heading1: '36px',   // Judul Utama
    heading2: '22px',   // Judul Pendukung
    label:    '12px',   // Tajuk
    body:     '9px',    // Paragraf (≈ 12px at standard screen density)
  },
  fontWeight: {
    regular: '400',
    medium:  '500',
    bold:    '700',
  },
} as const;

Note on body size: 9 pt is a print unit. At 96 dpi screen resolution this is ≈ 12 px. Verify against the final Storybook render before committing the pixel value.

Logo & graphic elements

  • Export the +J icon and full wordmark as SVG components in src/components/Logo/
  • Accept a variant prop: "icon" | "wordmark"
  • Accept a color prop: "white" | "black" | "brand" (maps to the three approved combinations)
  • The three graphic primitives (square, triangle, J-curve) can be exported as base SVG components for pattern composition

Iconography

Source the ~20 brand icons as SVG files in src/icons/, grouped by category. Publish as a separate entry point (ds-jakarta/icons) to keep tree-shaking clean.
